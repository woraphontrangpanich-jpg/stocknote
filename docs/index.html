รู้ก่อนขาย ว่าโบรกจะตัดล็อตไหนแอปดูพอร์ตหุ้นไทยแบบแยกทุกล็อตที่ซื้อ

ซื้อหุ้นตัวเดิมหลายรอบแล้วกำไรขาดทุนเด้งไปมาเพราะโบรกตัดแบบ FIFO? Stock Note แสดงทุกล็อตเป็นแท่งซ้อนกัน บอกกำไรตามโบรก ตามต้นทุนเฉลี่ย และกำไรจริงทั้งก้อน

ทำอะไรได้บ้าง

ทุกอย่างทำงานในเครื่องคุณ ข้อมูลไม่ถูกส่งขึ้นเซิร์ฟเวอร์ของใคร

แท่งล็อตแบบ FIFO

เห็นทุกล็อตซ้อนกัน บนสุดขายก่อน ลองลากจำนวนที่จะขาย แล้วดูว่าล็อตไหนโดนตัดและกำไรเท่าไหร่

กำไร 3 มุม

กำไรตามโบรก (FIFO) กำไรตามต้นทุนเฉลี่ย และกำไรรวมทั้งก้อนที่ไม่เด้งตามการตัดล็อต

กราฟเทคนิค

แท่งเทียน SMA EMA Bollinger RSI MACD Fibonacci อัตโนมัติ และเส้นต้นทุนของแต่ละล็อตบนกราฟ

เชื่อม Settrade Open API

ใส่ API key ของโบรกที่รองรับ เพื่อดูราคาสด ดึงรายการซื้อขาย และส่งคำสั่งจากแอป

หลายบัญชี

แยกสมุดล็อตตามบัญชี สลับบัญชีหรือออกจากระบบได้ บัญชีที่ไม่มี API ก็กรอกเองได้

ส่งออก Excel

ไฟล์ Excel มีสูตรจริง 5 ชีต ทั้งสรุปพอร์ต ล็อต ประวัติ และกำไรที่ขายแล้ว

วิธีติดตั้ง

ใช้เวลาประมาณ 1 นาที ไม่ต้องติดตั้ง Python หรือโปรแกรมอื่นเพิ่ม

  1. ดาวน์โหลดไฟล์ StockNote-windows.zip กดตรงนี้เพื่อดาวน์โหลด หรือดูทุกเวอร์ชันที่ หน้า Releases
  2. คลิกขวาที่ไฟล์ zip แล้วเลือก Extract All แตกไฟล์ไว้ที่ไหนก็ได้ เช่น Documents ห้ามเปิดจากในไฟล์ zip โดยตรง
  3. เปิดโฟลเดอร์ StockNote แล้วดับเบิลคลิก StockNote.exe ถ้า Windows ขึ้นหน้าจอสีน้ำเงิน "Windows protected your PC" ให้กด More info แล้ว Run anyway เพราะโปรแกรมยังไม่ได้ซื้อใบรับรองแบบเสียเงิน
  4. ปักหมุดไว้ใช้ครั้งต่อไป ตอนโปรแกรมเปิดอยู่ คลิกขวาที่ไอคอนบน Taskbar แล้วเลือก Pin to taskbar หรือคลิกขวาที่ StockNote.exe เลือก Send to แล้ว Desktop

ใช้กับโบรกไหนได้บ้าง

ทุกโบรกใช้สมุดล็อตได้ แต่การดึงข้อมูลอัตโนมัติและส่งคำสั่งจากแอป ต้องใช้โบรกที่เปิด Settrade Open API สำหรับหุ้น

  • ส่งคำสั่งจากแอปไม่ได้

คำถามที่พบบ่อย

หา API key ได้จากไหน

เข้า streaming.settrade.com ด้วย username เดียวกับแอป Streaming กดเมนู More แล้วเลือก API Key Management กด Generate จะได้ App ID และ App Secret (แสดงครั้งเดียว ให้คัดลอกเก็บไว้) ส่วน App Code อยู่ในหน้าเดียวกัน ลูกค้า InnovestX ไม่มีในหน้านี้ ให้ติดต่อ InnovestX เพื่อขอ key

เปิดใช้บนเว็บเลยโดยไม่ดาวน์โหลดได้ไหม

ยังไม่ได้ Stock Note ต้องรันโปรแกรมเล็ก ๆ ในเครื่องเพื่อเซ็นคำขอไปที่ Settrade ด้วย App Secret และดึงราคาหุ้น ซึ่งหน้าเว็บอย่างเดียวทำไม่ได้ และถ้าเอา App Secret ไปไว้ในหน้าเว็บก็ไม่ปลอดภัย โปรแกรมจึงรันในเครื่องคุณ เปิดได้เฉพาะจากเครื่องนี้ และไม่ส่ง key ไปที่อื่นนอกจาก Settrade

ข้อมูลเก็บไว้ที่ไหน ถ้าอัปเดตเวอร์ชันใหม่ข้อมูลจะหายไหม

ข้อมูลเก็บที่ %LOCALAPPDATA%\StockNote แยกจากตัวโปรแกรม อัปเดตโดยแตกไฟล์เวอร์ชันใหม่ทับได้เลย ข้อมูลไม่หาย และมีไฟล์สำรองอัตโนมัติวันละไฟล์ API key เก็บใน Windows Credential Manager

ใช้บน Mac หรือมือถือได้ไหม

ตอนนี้มีตัวติดตั้งสำหรับ Windows เท่านั้น บน Mac หรือ Linux รันจากซอร์สโค้ดได้ ถ้ามี Python 3.10 ขึ้นไป

git clone https://github.com/woraphontrangpanich-jpg/stocknote.git
cd stocknote
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python run.py
